# 组件与布局

以下尺寸来自 Keyfolio 桌面实现，单位是逻辑 pt；用于 Web 时可作为 CSS px 起点。保留角色、密度与比例，依据目标屏幕和内容调整。

## 桌面骨架

| 角色 | Keyfolio 基准 |
| --- | --- |
| 顶部操作区 | 高 64 |
| 主内容左右留白 | 常规 28；打开详情后 24 |
| 搜索宽度 | 常规 420；紧凑 280 |
| 详情侧栏 | 380，右侧独立占位 |
| 卡片间隔 | 横纵均 18 |
| 卡片最小布局宽度 | 约 300；按可用宽度计算列数 |

原项目列数：max(1, floor((deskWidth − 2 × gutter − panelWidth + 18) / 318))；关闭详情时 panelWidth 为 0。网格和键盘上下导航必须共用列数。

标题栏与桌面光场连续。详情像插入桌面的独立薄板，顶部接光，表面色和当前卡片相通。打开或关闭详情时，网格一次落到新布局，只有侧栏滑入或滑出。不能让网格在中间宽度不停换列。

迁移到窄屏时优先保证文字、点击目标与内容顺序；详情可改为独立页面或合适的抽屉，不照搬 380 宽侧栏和桌面多列。

## 内容卡片

| 参数 | 常规卡 | 紧凑卡 |
| --- | --- | --- |
| 高度 | 186 | 170 |
| 圆角 | 18 | 18 |
| 内边距 | 18 | 17 |
| 厂商标识尺寸 | 24 | 22 |
| 名称 | 22 / semibold | 20 / semibold |
| 机器标识 | 12.5 / mono，tracking 1.4 | 12 / mono，tracking 1.3 |
| 名称到机器标识间距 | 8 | 7 |
| 右上复制圆钮 | 30，内图标 13 | 28，内图标 12 |
| 异常标签 | 高 22，字 11 | 高 21，字 10.5 |
| 延迟文字 | 11 | 10.5 |

卡片上方留给身份标识和快捷操作；名称、机器标识与状态集中在下部。名称 tracking 为 −0.3。名称单行截断，需要时在详情中提供完整内容。

卡片始终使用深色受光表面，浅色主题中也不改成浅彩实心卡。卡面文字以白色为基准，掩码圆点通过透明度退后。普通文字标签不套用机器标识的等宽字距。

选中描边宽 2.5，放在卡片外侧，不侵占内容。复制反馈向左覆盖为“已复制”胶囊，原先位置与点击目标不变；空间重叠的星标淡出，不让标题或按钮移动。

### 状态表达

- 正常：以小圆点和必要的延迟数据表达；无须给每张卡放“正常”大标签。
- 处理中：保留位置，采用稳定的圆点或轻微明暗反馈；Keyfolio 不用旋转 spinner 作为这套卡片的状态语言。
- 异常：无效、网络异常、限流、权限或额度问题使用清晰文本标签；错误和警告有自己的语义色，不能只靠厂商颜色区分。
- 成功反馈：复制按钮变勾，一次性的角落光反馈；校验由 checking 进入 valid 时可轻脉冲一次，不在任意状态变化时闪烁。

## 详情与列表

详情中的 hero card、按钮、统计和容器由同一个对象光色派生，深浅逐级变化，保持文字对比。内边距和纵向主要间隔均为 18。Hero 圆角 16、内边距 17、名称 21 semibold、机器标识 12 mono。

列表是同一套物件的高密度呈现：中性行底、小型双色身份 tile、固定文字列、安静的健康状态。不要把整行染成厂商色。切换网格与列表用整层短交叉淡入淡出，筛选或滚动回来不重播整批入场。

## 按钮与输入

| 组件 | 基准 |
| --- | --- |
| 主/次按钮 | 高 38，圆角 10，水平内边距 18，13 semibold |
| 图标按钮 | 36 × 34，圆角 9；按实际场景适配 |
| 表单输入 | 圆角 10，1 宽边线；focus 改变底色与边线 |
| 键盘焦点 | ink × 55%，宽 2，向外留 3 |
| Toast | 12.5 semibold，水平 16 / 垂直 9，圆角 18 |

主操作随主题反转明暗；次操作采用透明或轻底、细边线。按钮 hover 使用轻微 wash；已经承载对象光的按钮提高自己的光强。默认按压 scale 0.97，可按组件适配。

不可用的中性主按钮降为安静的 chip 底色和次弱文字，避免成为醒目的灰块。带业务色的专用按钮可降低整体透明度。模态遮罩已使背景变暗时，不再把背景内每个控件重复变暗。

键盘焦点使用可见的中性外环，按组件轮廓绘制，不能被 overflow 裁切。若平台必须保留系统强调色，保留可用性并明确适配，不以隐藏焦点换取统一。

## 模态窗口

Keyfolio 使用窗口内居中模态：圆角 16，左右留白 24，标题区高 59，底部操作区高 65。标题 17 semibold；关闭钮 28 × 28、圆角 8。

遮罩为黑色：浅色主题 28%，暗色主题 50%。暗色模态外侧有 8% 白色的 1 宽细环。投影 CSS 等价为 0 30px 80px，黑色浅主题 30%、暗主题 65%。

背景操作在模态期间退出键盘循环，但保留滚动条占位；不要通过禁用整棵滚动容器导致背景网格突然变宽。Esc 关闭并恢复合理焦点。Keyfolio 的遮罩点击不关闭模态，迁移时依业务决定。

## 与设计相关的核验

按实际改动检查：hover 与 selected 是否可区分；复制反馈、字重变化和滚动条是否引起位移；长名称和中文是否截断得当；溢光、阴影、菜单与焦点环是否被裁切；打开详情后的选中对象是否仍可见。只在本次改动触及对应行为时扩展验证。
