# 光场与动效

## 空间和光源

桌面是连续表面，由顶部宽柔光照明，侧面、底部与角落渐暗。浅色像干净的冷白纸面，暗色保持近中性的深墨，顶部可有很轻的靛色。不要把它替换成全屏彩色光团。

卡片光由几部分组成：

1. 深色本体，维持文字区的遮光。
2. 右下角主光 core，中心聚集，带长而柔和的尾部。
3. 右侧副光 lobe，采用对象的第二色，比主光轻且位移更少。
4. hover 时靠近指针的小光 spot。
5. 卡片外的桌面溢光 pool；暗桌上表现为发光，浅桌上表现为带色的阴影。

卡面光裁切在圆角内，投影与溢光位于外层，可以越过卡片边界。各光层轮廓要缓慢归零，避免可见圆环、硬边或色带。主光移动不应侵入主文字列；必要时同步加深字底遮光。

不同对象可以改变光形、主副光比例和色相转向，保持同一种受光逻辑。普通信息区不需要套上对象光。

## 环境光状态

| 状态 | 结果 |
| --- | --- |
| 无悬停、无选中 | 桌面灯自身的光 |
| 有选中，无悬停 | 选中对象的完整光色进入桌面 |
| 稳定悬停其他对象 | 临时预览该对象的光色 |
| 悬停的正是选中对象 | 保持该对象完整光色 |
| 离开临时对象 | 回到当前选中对象；没有选中则回到桌灯 |

hover > selection > rest 是环境光的解析顺序。它不改变业务选择本身。

指针意图需要过滤：快速掠过、滚动把卡片送到静止指针下、键盘换选后的偶然命中，不立即换房间颜色。Keyfolio 参考值为 settle 90ms、静止起步 200ms、scrollQuiet 200ms；实际实现还结合速度、加速趋势和所有权。简化移植可采用稳定停留门控，并保证旧计时器不会覆盖新对象；只加无条件 hover 延迟不足以精确复刻原实现。

搜索框接住同一环境光，像坐在宽柔光池中，focus 时光池和边缘轻微增强。光池须充分扩散，不能变成输入框背后的实心亮板。

## 统一的时间语法

| Token | 时长 | 缓动 cubic-bezier | 角色 |
| --- | --- | --- | --- |
| press | 120ms | (0.2, 0, 0, 1) | 手指按下 |
| exit | 180ms | (0.4, 0, 1, 1) | 离开 |
| state | 240ms | (0.2, 0, 0, 1) | hover、focus、selection |
| enter | 480ms | (0.22, 1, 0.36, 1) | 面板与内容进入 |

quick 是 180ms 配 (0.2, 0, 0, 1)，与 exit 同时长但用途和曲线不同。模态进入采用 enter 曲线、320ms，从 y = −8、scale = 0.965、opacity = 0 回到完成态。

入场卡片从 y = 12、scale = 0.985 淡入。同一批同时开始，通过逐张增加时长展开，而不是逐张增加 delay：480ms + min(index, 12) × 70ms，最长 1320ms。只用于首次展开；筛选、滚动回来或切换布局不重复演出。普通新页面不必照搬整批卡片入场。

hover 可轻微提升物件、增强局部光、投影和溢光；点击目标的位置与布局保持稳定。网格旁详情入场用 enter，退出用 exit，卡片间切换使用 state；内容列在一个布局帧完成重新排列。

## 可选的常驻生命感

这是增强层，只在任务需要、设备预算允许时使用。先保证静态状态完整。

- 桌灯混合 7.3s 与 10.3s 两个周期，避免机械往返的同步感。
- 卡片光周期 5–9s，由对象身份稳定分散相位；不要全屏一起呼吸。
- 桌灯漂移参考为 x ±8 / 23s、y ±6 / 31s，表现为缓慢光照变化。
- 一次点击提交环境光可有 720ms 短促 bloom；checking → valid 的光反馈约 900ms；复制角落光反馈约 180ms。反馈服从实际事件，不循环发作。

这些周期来自当前源码的常量；亮度振幅随主题和渲染方式变化，不从旧 README 的概述直接抄百分比。

## 渲染与降级

静态光形和各状态优先预渲染并缓存；hover 尽量只改变图层 opacity / transform，避免每帧重绘光斑、噪声或动画 blur 半径。旧、新投影各画一次，再交叉淡入淡出。

macOS 可用 CALayer / render-server 动画；Web 可用缓存图层与 CSS compositor 属性。按照实际平台验证性能，不把“使用 transform”本身当作流畅的证据。装饰层不拦截输入，不进入辅助功能树。

Keyfolio 常驻呼吸与漂移在窗口被遮蔽、最小化、低功耗、Reduce Motion、显式关闭时停止；应用进入后台满 120s 也停止。Web 迁移可以在页面隐藏时立即暂停。Reduce Motion 下去掉位移、缩放、呼吸、漂移和 bloom，保留必要的短淡入淡出与清楚的静态选择状态。

光效中的对比度按最终合成后的实际显示计算，包括主副光移动及最亮状态；源码里的调色亮度估算不是 WCAG 对比度。正文目标 4.5:1，大字和关键非文字控件目标 3:1；不要仅根据 base token 宣称通过。
